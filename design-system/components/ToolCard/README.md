Die Toolkarte führt auf der Startansicht in ein Modul und zeigt in einem Satz, was es kann.

**Du lieferst:** Titel, einen Satz Beschreibung, bis zu vier Formatchips und das Tastenkürzel. Karten stehen in einem Raster mit 280 px Mindestbreite.

**Regeln**
- Icon in `surface-3`-Kachel, Linienstärke 1,5 px, 24 px groß.
- Hover hebt die Karte von `surface-1` auf `surface-2` und stärkt den Rahmen auf `line-strong`. Sie bewegt sich nicht.
- Das Etikett "NEU" (`kf-tool__tag`) bleibt vier Wochen nach einem Modul und verschwindet dann.
- Die Beschreibung nennt das Ergebnis, nicht die Technik ("Zusammenführen, teilen, drehen"), nie "Ghostscript" oder "FFmpeg".

**Don't**
- Kein Farbcode pro Modul. Alle Karten sehen gleich aus, das Icon unterscheidet.
- Keine Statistiken auf der Karte.
