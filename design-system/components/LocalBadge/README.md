Das Offline-Badge sagt auf jedem Screen, dass nichts den Rechner verlässt. Es ist das wichtigste Versprechen des Produkts.

**Du lieferst:** nichts, der Text ist fest. Das Badge liest den echten Netzwerkstatus der App, nicht eine Behauptung.

**Varianten**
- Badge `kf-local`: Schild-Icon in `success`, Text "100 % lokal". Sitzt unten in der Sidebar.
- Statusleiste `kf-local--bar`: Satz "Keine Daten verlassen diesen Rechner." und rechts `Netzwerk: aus` in Mono. Sitzt am Fuß jeder Workbench.

**Regeln**
- Das Icon in `success` ist türkis, die Aussage trägt das Wort. Die Farbe ergänzt sie nur.
- Blockiert die App tatsächlich alle Verbindungen, steht dort "aus". Gibt es eine, die der Nutzer erlaubt hat (etwa manuelle Update-Prüfung), steht das Wort "kurz an" und ein Banner erklärt sie.
- Der Klick öffnet eine Seite, die zeigt, wie die Garantie technisch umgesetzt ist.

**Don't**
- Nie anzeigen, wenn es nicht stimmt. Dann lieber ein Banner mit Warnung.
