Die Preset-Karte lässt aus drei bis vier Voreinstellungen eine wählen und nennt, was dabei typischerweise herauskommt.

**Du lieferst:** Titel, einen Satz zur Wirkung und eine erwartete Ersparnis als Mono-Zeile. Genau eine Karte ist gewählt (`is-selected`, `role="radio"`).

**Regeln**
- Die gewählte Karte trägt `accent-subtle` und einen gefüllten Radiopunkt in `accent-text`. Der Punkt macht die Auswahl auch ohne Farbe lesbar.
- Reihenfolge von stark nach schwach, die Standardwahl steht in der Mitte.
- "Zielgröße" öffnet beim Wählen ein Feld im Inspector, die Karte selbst bleibt gleich.
- Die Ersparnis ist eine Erwartung, kein Versprechen: "typisch", nie "garantiert".

**Don't**
- Nicht mehr als vier Karten. Danach wird es eine Liste im Inspector.
- Keine Icons in den Karten. Die Titel tragen die Unterscheidung.
